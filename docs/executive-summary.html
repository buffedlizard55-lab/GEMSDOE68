What this project does

GEMSDOE68 builds a fault-probability map for the northwestern Great Basin study area and turns it into a competition submission. The scientific question is which unmapped faults the existing USGS / INGENIOUS catalogue misses, and where the geophysical and topographic signature of a fault appears without a mapped trace.

The method in this lane is auto-context stacked refinement (Tu, CVPR 2008, doi:10.1109/CVPR.2008.4587436; extended TPAMI version pages.ucsd.edu/~ztu/publication/pami_autocontext.pdf): a first classifier scores every 100 m cell from the raw geophysical channels, then a second classifier is trained on those scores plus the raw channels, so it can learn the spatial regularities a per-pixel model cannot — continuity, parallelism, en échelon spacing. The refinement is applied twice.

Nothing here is a guess about the hidden test truth: every claim about accuracy is measured on a spatially blocked hide-and-recover holdout in which whole catalogue segments are withheld with a buffer, all catalogue-derived features are rebuilt from the visible faults only, and visible fault pixels are masked pixel-exactly before scoring.

The all-finite fallback writes 0 instead of NaN outside the footprint. It deliberately deviates from the shared validator's “NaN-only outside the footprint” rule, and is offered only because a NaN-blind range check on the upload form is the documented cause of the earlier “Predicted values must be in range [0, 1]” rejection. Prefer the primary file; use the fallback only if that error appears.

Step by step

  1. Download docs/downloads/GEMSDOE68-AC-stack2-20261012T042050Z-nan.tif from this site (or from docs/downloads/ in the repository).
  2. Open the competition data / submission page and choose New submission.
  3. Upload the .tif file (a .zip containing the single GeoTIFF also works; the repository ships both).
  4. Paste the submission name GEMSDOE68-AC-stack2 into the File to submit field's sibling Note box, or use the suggested note below.
  5. Submit, then record the receipt hash on the submission page and compare it with the sha256 printed here.

What is not claimed

  • No ORGANIZER-CONFIRMED score. The scored truth is login-walled; the only ground signal available in this checkout is the hide-and-recover holdout.
  • No leaderboard projection is written as a score. Owner-reported leaderboard values quoted anywhere in this repository are labelled as owner-reported, never as receipts.
  • The registry of prior rasters used for the uniqueness check is the one committed under registry/rasters/; it is not certified complete by the organisers.
