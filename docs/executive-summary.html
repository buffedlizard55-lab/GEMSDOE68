One single-band GeoTIFF, float32, EPSG:32611, 3730 × 3292, transform (100, 0, 243350, 0, -100, 4508550), values in [0, 1]. A .zip containing exactly one GeoTIFF is also accepted.

2. The form

  1. Open the submissions page and click New submission.
  2. File to submit → choose gems68-autoctx-40000-20261012T014104Z-zeros.tif.
  3. Note (optional) → paste GEMSDOE68 autoctx stage2 x1 budget 40000 rmin 2.4 offcat>2.0px
  4. Submit. The score appears on the submissions page; record it in registry/leaderboard.jsonl with the file sha256 so the number is traceable.

3. The range error

The portal rejects a file with “Predicted values must be in range [0, 1]” when any value is outside [0, 1] or is NaN where the organizer expects a number. The -zeros.tif twin has no NaN anywhere and every value is exactly 0.0 or 1.0, so it cannot produce that error. That is the file to upload.

4. Naming and the note

Name pattern: gems68-autoctx-<budget>-<UTC stamp>. The note names the method, the budget and the holdout gate so two runs can be told apart later.

5. Weekly cap

Submissions per week are capped by the organizer; check the cap on the submissions page before uploading. This repository never auto-uploads — promotion to a real slot is a separate human decision.
