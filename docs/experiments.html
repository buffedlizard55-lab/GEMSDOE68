Experiments (HOLDOUT-DTI only; nothing here is a leaderboard score)

Both experiments use the same hide-and-recover holdout (whole catalogue components withheld per quadrant with a 3 px feature collar, 12 px boundary erosion, visible faults masked pixel-exactly), the same emission rule at matched budgets, and a paired 20 km-block bootstrap for the CI. Experiment 1 trained stage 2 with the visible catalogue as both label and context source → cat_dist was 0 on every positive and took 95 % of the gain (IR-68-LEAK-01). Experiment 2 fixes this with hide-draw labels: withheld components are the positives and context comes from the remaining visible map.
