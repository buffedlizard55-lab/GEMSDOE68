How to make a submission (step by step)

  1. Download the primary file: ⬇ gems68-autoctx4-ext-bagged-25000dots-20261020T200722Z-3d070595-zeros.tif (or the ZIP containing only that TIFF). Verify its SHA-256 matches 99e00aa5f7137306271f12227dea5da476f8d2943a84fcfffe8dc4b94b43335c.
  2. Open the competition's submission page (login required) and click New submission.
  3. File to submit: choose the downloaded .tif (or .zip). The form accepts a single-band GeoTIFF matching the sample's CRS (EPSG:32611), shape (3730×3292) and geotransform.
  4. Note (optional, ≤140 characters): paste GEMSDOE68 autoctx4 ext+bagged s3; 25000 dots >2px off cat; HOLDOUT-DTI 0.1219 vs s1 0.0711 seed42; UNSCORED
  5. Submit. Copy the score from the receipt into registry/score_ledger.csv tagged ORGANIZER-CONFIRMED with the exact file name and SHA-256.

About the earlier "Predicted values must be in range [0, 1]" error

The primary file here is all-finite: 0.0 outside the footprint, values exactly 0.0 or 1.0 inside, no NaN, no nodata tag, no sentinel — so no cell can fall outside [0, 1]. Earlier family files were accepted by the portal in this "zeros" form. The published spec says data outside the bounds is null/NaN, so a NaN-outside twin (identical inside the footprint) is also published: it passes the shared gems.validate_submission in full (evidence/validator_shared_exp4_nan.json), while the zeros file fails only that validator's strict NaN-only-outside check by design (evidence/validator_shared_exp4_zeros.json). Upload the zeros file first; if the portal objects to anything, upload the NaN twin instead. Both were re-read from disk and verified cell-for-cell identical inside the footprint. The local validator re-reads the bytes on disk and checks: single band, float32, 3730×3292, EPSG:32611, pinned transform, no NaN/inf anywhere, min ≥ 0, max ≤ 1, zero positive pixels outside the footprint, zero positive pixels on the mapped catalogue.

Rules you should know

  • Weekly submission cap is shown on the submission page; promotion to a slot is a separate selector decision (rules PDF 96647).
  • Metric: distance-weighted Tversky index, α = 0.2 (FP), β = 0.8 (FN), 300 m triangular kernel (problem description).
  • Known/mapped faults are excluded from scoring; the truth is new faults mapped by the expert panel.
