2. Submit on DrivenData

  1. Go to DrivenData GEMS Prize → Submit.
  2. Click "New submission" or "Submit".
  3. Select the downloaded .tif file in "File to submit".
  4. Paste the note: GEMSDOE68 auto-context stacked refinement (Tu CVPR 2008); stage3, r=3px, 32000 dots; holdout-gated; fixed footprint 20261020 (118 characters, ≤ 140 limit).
  5. Click "Create" / "Submit".

3. If the portal says "Predicted values must be in range [0, 1]"

This error means the file contains values outside [0, 1] or NaN inside the footprint — or the portal's check incorrectly treats NaN outside as out-of-range.

Our primary file fixes this. GEMSDOE68-AC-stack3-r3-N32000-FIXED-20261020T193000Z-zeros.tif is all-finite: 0 outside the footprint, 0/1 inside, no NaN, min 0 max 1. It cannot trigger the error. The NaN-outside twin (-nan.tif) matches the competition's sample_submission format (NaN outside only), but if that still fails, use the zeros file — zeros is now primary for this reason.

The original 20261020T182552Z file had 3061 NaN inside the official footprint (wrong template); the FIXED file corrects this.

4. Verify

After submission, check the leaderboard for your entry under the submission name GEMSDOE68-AC-stack3-r3-N32000-FIXED-20261020T193000Z. Scoring may take some time to complete.
