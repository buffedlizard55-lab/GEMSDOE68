2. Submit on DrivenData

  1. Go to DrivenData GEMS Prize → Submit.
  2. Click "New submission" or "Submit".
  3. Select the downloaded .tif file in "File to submit".
  4. Paste the note: GEMSDOE68 auto-context stacked refinement (Tu CVPR 2008); stage3, r=3px, 32000 dots; holdout-gated (98 characters, ≤ 140 limit).
  5. Click "Create" / "Submit".

3. If the portal says "Predicted values must be in range [0, 1]"

This error means the file contains values outside [0, 1] or NaN inside the footprint.

Our nan.tif variant has NaN outside the footprint only — which matches the competition's sample submission format. If the portal's range check treats NaN as out of range, download the all-finite fallback instead:

GEMSDOE68-AC-stack3-r3-N32000-20261020T182552Z-zeros.tif

The fallback writes 0 outside the footprint and contains no NaN at all.

4. Verify

After submission, check the leaderboard for your entry under the submission name GEMSDOE68-AC-stack3-r3-N32000-20261020T182552Z. Scoring may take some time to complete.

No organiser score is claimed on this site. Every number here is a local HOLDOUT-DTI measurement.
