# H68-M1 provisional scored attempt — NOT valid release evidence

The *same preregistered* H68-M1 (magnetic-edge-tangent auto-context, seed 20, 38,000-dot budget) was fitted after an initial infrastructure-only crash in the shared `gems57.evaluate_holdout` (`fold.get` eagerly read a missing fallback key). The first fully scored attempt finished at 2026-10-20 18:43 UTC and its JSON and console log are archived here **before rerunning**. They are **not** the canonical holdout, and their pooled DTI/CI numbers must not be used for model selection or organizer-score claims.

**Why quarantined?** A code review while this attempt was already running, *before its result was visible*, found that `gems68.emission.emit_dots` treated all equal-valued LightGBM plateau cells as separate 5×5 local maxima; an arbitrary top-k could keep adjacent dots despite the declared 5×5 NMS rule. The matched budget existed, but the spatial dot-separation rule was not actually enforced. The shared emitter was corrected with deterministic greedy suppression and regression tests before inspecting the provisional output. The per-feature canary also marked constant/undefined channels as “not cleared”; mathematically a constant feature has AUC 0.5 (all ties), so this separate shared canary semantic was fixed with a regression test. Genuine non-finite features still fail closed. Neither repair changes H68-M1's physical hypothesis, train/test split, 38k budget, threshold, seed or model hyperparameters.

**Diagnostic observation only:** inherited provisional evaluator `gems57-pooled-hide-v2.1`, 11,321 withheld catalogue pixels (4,832 in the >1 km stratum), stage1 pooled DTI 0.0809897 [0.0693971, 0.0929054], stage2 0.0813852 [0.0699167, 0.0921909], stage3 0.0783890 [0.0667961, 0.0897594]; *both provisional stage2 paired gates failed* (overall Δ+0.0006825, SE0.0041626, t0.164; >1 km Δ+0.0012969, SE0.0025814, t0.502). The highest measured individual-feature directional AUC was 0.6696; 165 channel/fold occurrences had undefined AUC under the old conflated constant/non-finite rule, not 165 proven leakages. These are **quarantined HOLDOUT-DTI diagnostics**, not organizer-confirmed scores, not a reason to tune after inspection, and not used in the current run card. No raster was produced by this attempt and no competition slot was used.

The single allowed corrected rerun of exactly the preregistered H68-M1 uses `src/gems68/emission.py` version `gems68-plateau-safe-nms-v2` and reports the full per-feature canary list. If it still fails either paired gate or any actual leakage canary, the lane ends with **no public download**. Source and history remain in Git for line-by-line audit.
