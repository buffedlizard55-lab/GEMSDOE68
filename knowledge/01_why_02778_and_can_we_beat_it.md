## 1. What the official objective actually rewards

Per the [DrivenData problem description and scoring rule](https://www.drivendata.org/competitions/306/competition-doe-gems/page/967/), distance-weighted Tversky uses a 300 m triangular kernel, α = 0.2 and β = 0.8. With unknown truth fault cells G, predicted probability field p(x), kernel k(d) = max(0, 1 − d / 300 m), weighted coverage T = Σ[g ∈ G] max[x] p(x) k(d(x,g)), emitted mass S = Σ[x] p(x), and mass self-credit M = Σ[x] p(x) max[g ∈ G] k(d(x,g)), the index is

```
T / (T + 0.2 · (S − M) + 0.8 · (|G| − T))
  = T / (0.2 · (T + S − M) + 0.8 · |G|).
```

This identity is exact for this evaluator; unlike pixelwise intersection-over-union, multiple nearby dots need not provide independent truth coverage. **Illustrative marginal calculation, not a strategy tuned to hidden labels:** if a new unit-mass dot contributes g additional truth coverage and m self-credit, the score increases exactly when `g > 0.2 · current_DTI · (g + 1 − m)`. If it covers *one previously uncovered* truth cell with kernel credit `k` and no other cells, `g = m = k` and the condition simplifies to `k > 0.2 · current_DTI`. If its nearby truth is already covered, `g` can be zero even if `m` is large, so the simplified `k` rule **does not apply**. At a merely *hypothetical* DTI of 0.2778 the one-cell illustrative threshold would be 0.05556; that is not an estimate of unknown truth locations, nor proof of H33's causal mechanism.

Consequences supported by the arithmetic: binary, thin, well-spaced lines can capture many distinct faults per emitted unit; arbitrary wide masks pay more false-positive mass; **uncovered truth is more heavily weighted** (β = 0.8); over-pruning can also hurt recall. The desired dot count cannot be established from a local masked-catalogue proxy alone.

## 2. What the owner H33 record can and cannot establish

A historical raster with `h33-h33-2-b2-20261004T220000Z-e5eb6e7e-zeros` in its name is in the pinned accessible registry. Its inherited audit lists file SHA-256 `c55bafc470054e8271dcb89347a17e07fefe50de6af6e6ba6c4b169ef7ab6fa9`, 37,654 binary dots, single-band float32 EPSG:32611 and zero exterior. **These are artifact properties, not a receipt.** A second H33-named registry path has the *same byte hash*; do not treat it as an independent model. The earlier calculations and detailed ladder are archived at [`evidence/archives/2026-10-12/why-02778-old.md`](../evidence/archives/2026-10-12/why-02778-old.md).

The owner sequence reported H19-5 0.1922 (121,131 pixels), dotted d1.5 0.2477 (60,069), d2.8 0.2600 (44,090), h27-4 0.2708 (40,199) and h33-2-b2 0.2778 (37,654). These are **OWNER-REPORTED and not independently re-scored**; the user-supplied number has no authenticated submission hash/receipt in this checkout. If those scores were obtained from the same organizer labels and the files differ only by pruning, they are *consistent with* better emitted-mass allocation: less redundant halo around the mapped fault catalogue, higher predicted mass on relatively uncovered truth. This is a conditional, not an experimental causal ablation; multiple fields, masks or scoring dates could confound it.

The public competition target is **new expert-mapped faults**, rather than reproducing the old fault catalogue or predicting vents. Removing dots close to catalogue faults may reduce false positives if those labels are masked from evaluation, but it may also remove genuine nearby undiscovered strands. An owner ladder does not establish the optimum distance everywhere, especially away from high-confidence catalogue coverage.

## 3. Can magnetic-edge-tangent auto-context beat it?

It might improve *line ranking* by using an out-of-fold first-stage map plus ±1–15-pixel orientation samples, anisotropic smooths, raw gradients/tilt/scarp information and catalogue context masked on the target block. Magnetics can track buried structural/lithologic boundaries where a surface scarp fades, but east–west survey striping, igneous margins and lithologic contacts are realistic confounders ([USGS GeoDAWN](https://www.usgs.gov/data/geodawn-airborne-magnetic-and-radiometric-surveys-northwestern-great-basin-nevada-and)). The [Tu–Bai paper](https://pages.ucsd.edu/~ztu/publication/pami_autocontext.pdf) motivates iterative probability-context classification; it does not validate geothermal inference.

[H68-M1's dated preregistration](../docs/research/2026-10-20-autocontext-hypotheses.md) freezes four buffered outer folds, four inner blocks per outer, 38,000 matched dots and two hard paired >2-SE tests: all withheld positives **and** those >1 km from mapped faults. It tests every individual feature for leakage AUC >0.90. This is **HOLDOUT-DTI** on withheld *catalogue* lines, not organizer-confirmed performance on private newly interpreted faults. An improvement on these folds would not by itself prove a score above 0.2778; a failure means **do not offer a TIFF for download**. See the [current results](../docs/results.html) and [current decision](../docs/index.html). There is no authenticated DrivenData submission receipt for H68-M1.
